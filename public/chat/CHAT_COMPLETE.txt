// ============================================================================
// 🔧 FLUX DE TRAITEMENT D'UNE QUESTION
// ============================================================================

User Types: "Comment modifier ma réservation?"
     ↓
Frontend (script.js): Envoie à l'API
     ↓
POST /app/api/chat.php
     ↓
ChatBot::processQuery()
     ↓
  1️⃣ searchFAQ()
     → Cherche mots-clés: "booking", "modify", "baggage", etc.
     → Si trouvé: Retourne réponse FAQ
     ↓
  2️⃣ searchDatabase()
     → Cherche infos dans BD (trajets, réservations)
     → Requêtes: SELECT * FROM trajets, reservations
     → Si trouvé: Retourne infos + réponse contextualisée
     ↓
  3️⃣ queryExternalAPI()
     → Cherche météo, taux change, etc
     → Appels: OpenWeatherMap, ExchangeRate API
     → Si trouvé: Retourne données + réponse
     ↓
  4️⃣ Fallback
     → Si aucune source: suggestion générique
     ↓
logConversation() → Sauvegarde dans logs/chat_conversations.json
     ↓
Retourner JSON: { response, source, data? }
     ↓
Frontend: Affiche réponse + source
          Utilisateur peut voter (👍 utile / 👎 pas utile)

// 🧠 EXEMPLES D'UTILISATION AVANCÉE
// ============================================================================

1. Appeler le chat via JavaScript:

async function askChat(question, lang = 'fr') {
  const formData = new FormData();
  formData.append('question', question);
  formData.append('lang', lang);
  
  const response = await fetch('/app/api/chat.php', {
    method: 'POST',
    body: formData
  });
  
  const data = await response.json();
  console.log('Réponse:', data.response);
  console.log('Source:', data.source);
}

// Utilisation
askChat("Comment réserver?", "fr");

2. Accéder à l'historique localStorage:

const history = JSON.parse(localStorage.getItem('chat_history'));
console.log('Nombre de questions:', history.length);
console.table(history);

3. Exporter les données:

function exportChatData() {
  const data = localStorage.getItem('chat_history');
  const element = document.createElement('a');
  element.setAttribute('href', 'data:text/json;charset=utf-8,' + 
    encodeURIComponent(data));
  element.setAttribute('download', 'chat_history.json');
  element.click();
}

4. Récupérer les patterns d'apprentissage:

fetch('/app/api/chat-admin.php?action=get_patterns')
  .then(r => r.json())
  .then(data => {
    console.log('Stats:', data.patterns);
  });

Q: Le chat ne répond pas
A: 1. Vérifier que /app/api/chat.php est accessible
   2. Ouvrir DevTools (F12) → Network → Voir erreurs fetch
   3. Vérifier que logs/ a les droits d'écriture

Q: Les réponses viennent du fallback
A: 1. Ajouter des données FAQ dans index.html
   2. Vérifier que la BD est accessible
   3. Vérifier les mots-clés (voir searchFAQ() dans chat.php)

Q: Le learning ne fonctionne pas
A: 1. Vérifier que logs/chat_conversations.json existe
   2. Vérifier les permissions d'écriture sur logs/
   3. Vérifier la console JS pour les erreurs
